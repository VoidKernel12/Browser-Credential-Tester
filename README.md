 # Browser Data Telemetry & Portal Testing Tool

A lightweight web portal testing, asset cloning, and live telemetry logging tool built with Python and Flask, optimized for Termux and Linux environments.

## Features
- **Live Terminal Telemetry:** Instantly captures and displays incoming target IP addresses, User-Agents, browser languages, and timestamps in real-time.
- **Advanced Asset Cloning:** Inspects and clones target website structures while safely rewriting form actions for local testing.
- **Clean Interface:** Suppresses default web server noise to provide a focused, color-coded terminal view.
- **Custom Security Template:** Includes a modern, glassmorphism-styled Enterprise SSO template for baseline testing.
